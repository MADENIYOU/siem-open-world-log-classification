## Limites

- Les sources ont été vérifiées par leur page de résumé : aucune n'a été lue en entier. Les apports décrits dans le tableau se limitent à ce que dit le résumé ; les chiffres, protocoles et conditions d'emploi doivent être relus dans l'article avant toute affirmation forte.
- Certains lieux de publication (ICML 2001 pour M69, ICML 2005 pour M68, SIGIR 2009 pour M88, Machine Learning 2007 pour M70, AAAI-98 pour M13, NIPS 2017 pour M6, ICDM 2008 pour M29) ne figuraient pas sur la page ouverte ; ils sont donnés d'après l'usage bibliographique courant ou des résultats de recherche et sont signalés « page muette » ou entre parenthèses. À recouper avant le dépôt final.
- Les PDF ont été lus par extraction du premier feuillet ; l'extraction donne le résumé fidèlement mais n'atteste pas la version finale publiée (certains PDF sont des préimpressions d'auteurs).
- Les outils de lecture résument les pages avec un petit modèle : les titres et auteurs ont été comparés avec les résultats de recherche, mais une coquille reste possible, surtout dans les longues listes d'auteurs.
- Lacunes de couverture : aucune source récente trouvée sur le k-means utilisé comme classifieur, ni sur les mélanges de gaussiennes (seule l'analyse discriminante gaussienne de M26 s'en approche), ni sur NER propre aux logs de sécurité (SDLog traite des données sensibles, pas de la taxonomie ECS). Pour le TF-IDF seule la documentation d'outil a été ouverte, pas un article fondateur.
- La plupart des méthodes OOD récentes (ASH, SCALE, DICE, NNGuide, SHE, Gram) sont évaluées en vision par ordinateur ; leur transfert aux embeddings de texte n'est pas démontré par ces résumés (seul M27 traite le texte).
- Le moteur de recherche est restreint aux États-Unis et l'exhaustivité n'est pas garantie.
